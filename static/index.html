Git 集成

配置你自己的 GitHub / GitLab 访问令牌 · 修改后自动保存
GitHubgithub.com · 支持多个 Token
可同时配置多个 Token：「组织名」留空的条目是其余仓库的兜底（经典 token，或个人的 fine-grained token）；填了组织名（如 acme）的条目只用于该组织的仓库（fine-grained token，Resource owner 需选该组织并在组织的 Settings → Third-party access 批准；经典 token 若组织启用 SAML SSO 还需对令牌执行 SSO 授权）。只读即可：fine-grained 选 Contents: Read-only，经典勾 repo（或 public_repo 仅公开仓库）。Token 保存后只显示尾 4 位。
GitLabgitlab.com 或自建实例
最小范围 read_api（个人访问令牌，只读 API）；访问私有项目需要 Reporter 及以上角色。自建实例使用自签名证书时，连接会报 certificate verify failed（含 EE certificate key too weak），勾选跳过校验即可。
令牌与服务器地址保存在你的账号下，接口不会回传令牌；令牌留空表示保持已保存的值。仓库状态读取和 commits 抓取通过 GitHub / GitLab REST API 使用你的配置；所有 GitLab 仓库统一使用这里的 GitLab 服务器地址；GitHub 未配置令牌时只能访问公开仓库。

内部 Agent LLM

周报生成与语音 TODO 整理都通过内部 Agent 调用 · 修改后自动保存
API Key 只保存在本机数据库，接口不会回传；留空表示保持已保存的值。图片识别模型复用上面的 API Key，用于识别上传图片中的文字和内容；填了图片识别 API 地址时按 OpenAI 兼容协议调用该地址（部分 Anthropic 兼容网关会丢弃图片）。API 地址留空时，OpenAI 使用 https://api.openai.com/v1，Anthropic 使用 https://api.anthropic.com；也可以指向任何 OpenAI 兼容或 Anthropic 兼容的自建端点。Embedding 模型填了才启用 CLI/接口的向量检索，调用 Embedding API 地址（留空时为 API 地址）下的 /embeddings，需 OpenAI 兼容端点（Anthropic 官方无嵌入 API）——LLM 走远程网关、嵌入走本地服务时，把 Embedding API 地址单独指向本地。

语音 TODO

浏览器只负责录音并转为 16k WAV，转写由识别服务地址对应的本地服务完成（如 whisper.cpp 的 /inference，或任何 OpenAI 兼容转写端点）；转写文本由内部 Agent 整理成 TODO 项，整理失败时按原始转写创建。

提交超过容量时新任务会被拒绝；并行执行数决定同时运行的任务数，其余在队列中按提交顺序等待。修改立即生效，无需重启服务。

文件冷存储

每小时检查，将上传超过一个自然月的原文件转存到此目录，仍可预览和下载。目录需保持可访问，不能与应用数据或完整备份目录重叠。

数据备份

定时备份 SQLite 数据库与上传文件到目标目录 · 修改后自动保存
每次备份包含 SQLite 数据库的在线快照、uploads 上传文件与已转存的冷存储文件，压缩为目标目录下的 zreport-backup-日期-时间.zip 文件；超出保留份数的旧备份自动清理，仅处理该命名规则的 ZIP 文件和旧版目录，目标目录里的其他文件不受影响。目标目录建议选本机其他磁盘或外接存储，避免与数据同盘。调度按北京时间计算，修改立即生效，无需重启服务。
