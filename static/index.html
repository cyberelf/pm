Git 集成

配置你自己的 GitHub / GitLab 访问令牌
GitHubgithub.com · 支持多个 Token
可同时配置多个 Token：「组织名」留空的条目是其余仓库的兜底（经典 token，或个人的 fine-grained token）；填了组织名（如 acme）的条目只用于该组织的仓库（fine-grained token，Resource owner 需选该组织并在组织的 Settings → Third-party access 批准；经典 token 若组织启用 SAML SSO 还需对令牌执行 SSO 授权）。只读即可：fine-grained 选 Contents: Read-only，经典勾 repo（或 public_repo 仅公开仓库）。Token 保存后只显示尾 4 位。
GitLabgitlab.com 或自建实例
最小范围 read_api（个人访问令牌，只读 API）；访问私有项目需要 Reporter 及以上角色。自建实例使用自签名证书时，连接会报 certificate verify failed（含 EE certificate key too weak），勾选跳过校验即可。
令牌与服务器地址保存在你的账号下，接口不会回传令牌；令牌留空表示保持已保存的值。仓库状态读取和 commits 抓取通过 GitHub / GitLab REST API 使用你的配置；所有 GitLab 仓库统一使用这里的 GitLab 服务器地址；GitHub 未配置令牌时只能访问公开仓库。

内部 Agent LLM

周报生成与语音 TODO 整理都通过内部 Agent 调用
API Key 只保存在本机数据库，接口不会回传；留空表示保持已保存的值。API 地址留空时，OpenAI 使用 https://api.openai.com/v1，Anthropic 使用 https://api.anthropic.com；也可以指向任何 OpenAI 兼容或 Anthropic 兼容的自建端点。

语音 TODO

按住右下角麦克风说话，自动整理成 TODO
浏览器只负责录音并转为 16k WAV，转写由识别服务地址对应的本地服务完成（如 whisper.cpp 的 /inference，或任何 OpenAI 兼容转写端点）；转写文本由内部 Agent 整理成 TODO 项，整理失败时按原始转写创建。
